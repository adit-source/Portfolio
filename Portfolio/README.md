# Aditya Kumar — Data Analyst Portfolio

A professional, responsive Data Analyst portfolio website built with HTML, CSS, Tailwind CSS CDN, and Alpine.js.

## Project structure

```text
aditya-data-analyst-portfolio/
├── index.html
├── README.md
├── .gitignore
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
        ├── profile.jpg
        └── favicon.svg
```

## Run locally

Open `index.html` in a browser, or use VS Code Live Server.

## Deploy free

Recommended: GitHub Pages, Netlify, or Vercel.

### GitHub Pages

1. Create a GitHub repository, e.g. `aditya-data-analyst-portfolio`.
2. Upload all files while keeping the folder structure.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for the published URL.

## Notes

- Tailwind CSS and Alpine.js are loaded from CDNs, so an internet connection is required for those libraries.
- The profile image is stored locally in `assets/images/profile.jpg`.
- Update project links, phone number, email, LinkedIn, and GitHub details in `index.html` whenever needed.
