# Aditya Kumar — Portfolio

A professional, responsive Data Analyst portfolio website built with HTML, CSS, Tailwind CSS CDN, and Alpine.js.

## Project structure

```text
Portfolio/
├── index.html
├── README.md
├── .gitignore
└── assets/
    ├── css/
    │   └── style.css
    ├── js/
    │   └── main.js
    └── images/
        ├── profile.jpg
        └── favicon.svg
```

## Notes

- Tailwind CSS and Alpine.js are loaded from CDNs, so an internet connection is required for those libraries.
- The profile image is stored locally in `assets/images/profile.jpg`.
- Update project links, phone number, email, LinkedIn, and GitHub details in `index.html` whenever needed.
